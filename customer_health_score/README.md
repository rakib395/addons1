\# Customer Health Score - Odoo 18



This is a custom Odoo 18 module developed to analyze and track customer performance based on sales data. This module is part of a project for Mindsynth Technologies.



\# 1. Key Features

1\. Health Scoring: Automatically calculates a health score for each customer based on their activity.

2\. Sales Analysis: Tracks order frequency, payment behavior, and revenue trends.

3\. Health Status: Categorizes customers into different states like "Good" or "At Risk".

4\. Automation: Includes a scheduled action for weekly health updates.



\# 2. Dependencies

1\. Base module.

2\. Sale module.



\# 3. Installation

1\. Clone or copy this folder into your Odoo custom\_addons directory.

2\. Restart your Odoo server.

3\. Update the Apps list in Odoo.

4\. Install the module using the following command:

&#x20;  python odoo-bin -d your\_database\_name -i customer\_health\_score
